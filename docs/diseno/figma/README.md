# Diseño de AlertaOax en Figma

Pantallas finales del rediseño «Radar topográfico» exportadas desde la aplicación real.

- **Archivo de Figma:** [AlertaOax — Diseño final](https://www.figma.com/design/x2KNlxZaO5HgcY2pDfVkQa/AlertaOax-%E2%80%94-Dise%C3%B1o-final.?node-id=1-6377)
- `svg/`: 27 pantallas (escritorio 1440 px y celular 390 px) más la hoja `00_Sistema_de_diseno.svg`. Se importan arrastrándolas a Figma y quedan como capas editables.
- `png/`: las mismas pantallas en imagen, para el reporte.

Incluye: acceso, registro, alertas, mapa, prepárate, reportar, mis reportes (ciudadano); publicar y reportes (autoridad); resumen, autoridades y usuarios (administrador); y versiones en modo oscuro.

Nota: desde AO-416 la aplicación usa las fuentes del sistema (Segoe UI, San Francisco, Roboto); estas pantallas conservan Space Grotesk/Inter del rediseño anterior. Las pantallas de verificación de correo y Mi perfil (AO-416) no están en este juego.
